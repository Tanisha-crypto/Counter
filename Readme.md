# 🔢 Counter App

Counter App is a simple web app for increasing, decreasing, and resetting a number.

## ✨ Features

- Increase the count by one
- Decrease the count by one
- Reset the count to zero
- Supports negative values
- Simple button-based interaction

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

```bash
git clone https://github.com/Tanisha-crypto/Counter
```

Open `counter.html` in your browser to use the app. No installation or build step is required.

## 🎮 How to Use

1. Open the app in your browser.
2. Click **Increase** to add one to the count.
3. Click **Decrease** to subtract one from the count.
4. Click **Reset** to return the count to zero.
